## Продукт

Windows-приложение: медиа-контролы в таскбаре для музыки и видео.

Когда играет источник вроде Spotify, Яндекс Музыки, YouTube или другого плеера, в таскбаре видно:

- обложку / превью
- название трека или видео (и при наличии — исполнитель / канал)
- кнопки назад, пауза/плей, вперёд
- прогресс / длительность
- громкость именно этого источника: клик открывает слайдер, можно сделать тише или громче без трогания системной громкости

Та же схема для видео, не только для песен.

## Целевое поведение

1. Подхватывать активный медиа-источник системы (SMTC / session API).
2. Показывать карточку в зоне таскбара (или рядом с ним), без лишнего UI.
3. Play / pause / next / previous через системные команды медиа-сессии.
4. Per-app volume: менять громкость конкретного audio session, не master volume.
5. Если источников несколько — выбрать активный или переключаться между ними (детали UX уточняются).

## Стек (черновик)

- Платформа: Windows 10/11
- Язык / UI: уточняется (предпочтительно native: C# / WinUI 3 или WPF; Electron только если native окажется тупиком)
- Медиа-метаданные и транспорт: Windows System Media Transport Controls / GlobalSystemMediaTransportControls
- Громкость по приложению: Windows Core Audio (IAudioSession*)
